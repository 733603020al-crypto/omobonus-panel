# Omobonus · облачная панель

Статическая страница (GitHub Pages). Данных и ключей здесь нет: всё читается и пишется в приватный репозиторий omobonus-workspace через API GitHub личным ключом пользователя, который живёт только в памяти вкладки.

- «Задачи» — журнал отложенных задач (`tasks/deferred-tasks.json`).
- «SEO-панель» — результаты последней SEO-проверки (`seo/panel-data.json`, публикуются с компьютера). Интерфейс (`seo.html`, `seo.css`, `seo-app.js`) собирается из шаблона локальной SEO-панели сайта: `node tools/build-seo.mjs`.
