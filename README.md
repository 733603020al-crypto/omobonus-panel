# Omobonus · облачная панель

Статическая страница (GitHub Pages): https://733603020al-crypto.github.io/omobonus-panel/

Это облачная сборка новой панели Omobonus Workspace (код — папка `app` приватного репозитория omobonus-workspace). Данных и ключей здесь нет: после входа личным ключом GitHub (см. «Вход» ниже) всё читается и пишется в приватный omobonus-workspace через API GitHub:

- «Задачи» — `tasks/deferred-tasks.json` (те же правила, что у локальной панели);
- «SEO-панель» — результаты проверки `seo/panel-data.json` (публикуются с компьютера), решения — `seo/decisions.json` (тот же файл, что у локальной панели).

Вход: ключ GitHub вводится один раз на устройстве и хранится только в браузере, зашифрованным вашим паролем; дальше — только пароль.

Обновление: в `omobonus-workspace/app` выполнить `npm run build:cloud` и скопировать содержимое `dist` в корень этого репозитория (папку `old` не трогать).

Прежняя облачная панель сохранена в папке `old` (https://733603020al-crypto.github.io/omobonus-panel/old/).
